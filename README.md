# 🎓 UniConnect — Student Social & Study Hub

A modern, vibrant, all-in-one web platform designed specifically for college and university students to socialize, find study buddies, discover campus clubs, and attend events.

---

## 🌟 Key Features

### 1. 🚀 Campus Buzz & Social Feed
- **24-Hour Campus Stories**: Share visual moments across campus with quick reactions.
- **Rich Student Posts**: Academic questions, dining hall hacks, housing listings, lost & found, and marketplace posts.
- **Interactive Campus Polls**: Real-time vote percentage bars and live tallies.
- **Anonymous Mode ("Anonymous Cougar")**: Safe, candid confessions and honest peer feedback.
- **Full Social Interactions**: Likes, fire 🔥, helpful 💡, comments, and post bookmarking.

### 2. 👥 Study Pod Matchmaker & Live Focus Lounge
- **Course-Specific Matching**: Filter by course codes (e.g., `CS 310`, `BIO 220`, `MATH 240`, `ECON 202`).
- **Study Style Filtering**: Whiteboarding, flashcards, active recall, or silent Pomodoro.
- **One-Click Pod Invitations**: Real-time confetti celebrations and spot tracking.
- **Built-in Pomodoro Focus Timer**: 25-minute focus intervals and 5-minute study breaks directly inside the lounge.

### 3. 🎪 Clubs & Student Guilds
- **Diverse Organizations**: Tech & AI, Photography, Hackers, Hiking, Esports, and Women in STEM.
- **One-Click Membership**: Instantly join or leave clubs.
- **Club Announcements & Meeting Times**: Real-time updates on upcoming meetups.
- **Club Registration**: Launch and register new campus organizations.

### 4. 📅 Campus Events & Gatherings
- **Campus Calendar**: Filter by Hackathons, Socials, Study Crams, Sports, and Career Fairs.
- **Special Highlights**: Free food indicators, therapy dog sessions, and tournament prizes.
- **RSVP Tracking**: Keep track of events you are attending.

### 5. 💬 Real-Time Student Chatrooms & Quick Drawer
- **Dedicated Channels**: `#general-campus`, `#study-grind`, `#campus-events`, `#lost-and-found`, `#student-market`.
- **Live Slide-Out Drawer**: Chat with peers from any view without losing your place.
- **Online Presence**: Active student count and online indicator.

### 6. 👤 Student Profile & Campus Reputation
- **Campus Karma**: Points earned by creating study pods and helping peers.
- **Achievements & Badges**: Study Pod Leader, Algorithm Solver, Night Owl, and Verified Student.
- **Course & Interests Customizer**: Personalized profile details.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite 8, Tailwind CSS v4
- **Icons**: Lucide React
- **Animations & Effects**: Canvas Confetti, Tailwind CSS animations
- **Persistence**: LocalStorage with realistic mock campus data

---

## 🏃 Getting Started

### Run Development Server
```bash
npm install
npm run dev
```
Open **[http://localhost:5173](http://localhost:5173)** in your browser.

### Build for Production
```bash
npm run build
```
The optimized bundle will be in the `dist/` directory, ready to deploy to Vercel, Netlify, or any static host.
